## Hi, I'm Fangzhi Li 👋

I'm an M.S. student in Computer Science at **William & Mary**, working in the D3I Lab with [Prof. Haipeng Chen](https://haipeng-chen.github.io) and [Prof. Qingyun Wang](https://eaglew.github.io). **I'm applying to PhD programs for Fall 2027.**

I study **post-training and reinforcement learning for LLM agents that interact with users and environments**. My recent work uses interactive Text-to-SQL as a testbed: training small LMs to work out what a user wants and act on a live database over multiple turns, and building systems that keep users in control of what the agent does. Longer term, I want to build self-improving agents that learn from their own experience.

**Interests:** LLM post-training & RL · interactive agents · human–AI interaction · self-improving agents

### 🔬 Research

- **Post-training interactive Text-to-SQL agents** *(lead, 2026–present)*: training small LMs to clarify requests with a simulated user while acting on a live database.
- **[AurigaSQL](https://github.com/wmd3i/AurigaSQL)** *(first author, 2026)*: an open-source interactive Text-to-SQL assistant that keeps users in control of the agent.
